# Парсер цитат (Python Scraper)

Скрипт для автоматического сбора данных с сайта `quotes.toscrape.com`. 
Демонстрирует навыки парсинга веб-страниц, обработки ошибок и экспорта данных в Excel.

## 🎯 Задача
Клиенту требовалось собрать базу цитат (текст, автор, теги), отфильтровать только те, у которых **больше 2 тегов**, и выгрузить результат в удобный формат Excel.

## 🛠 Стек технологий
* **Python 3.12**
* **Requests** — для безопасных HTTP-запросов (с подменой User-Agent и таймаутами).
* **BeautifulSoup4** — для навигации по DOM-дереву и извлечения данных.
* **Pandas** — для очистки, фильтрации и экспорта в Excel.
* **Openpyxl** — движок для работы с `.xlsx` файлами.

## 🚀 Как запустить
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/agiknightt/scraper_portfolio.git
   cd scraper_portfolio
```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
   (Создайте файл requirements.txt в репозитории и впишите туда: requests, beautifulsoup4, pandas, openpyxl)
3. Запустите скрипт:
   ```bash
   python scraper_portfolio.py
   ```

📌 Особенности реализации

· Защита от блокировок: Подмена заголовка User-Agent, задержки time.sleep() между запросами.
· Отказоустойчивость: Обработка сетевых ошибок через try/except, таймауты на запросы (не зависнет, если сайт упал).
· Очистка данных: Преобразование списков тегов в строку через запятую для корректного отображения в Excel.
