# Парсер цитат (Python Web Scraper)

Скрипт для автоматического сбора данных с сайта [quotes.toscrape.com](https://quotes.toscrape.com). Демонстрирует парсинг веб-страниц, обработку ошибок и экспорт данных в Excel.

## Задача

Собрать базу цитат (текст, автор, теги), оставить только записи, у которых **больше 2 тегов**, и выгрузить результат в Excel.

## Стек

- **Python 3.12**
- **Requests**: HTTP-запросы с подменой User-Agent и таймаутами
- **BeautifulSoup4**: навигация по DOM и извлечение данных
- **Pandas**: очистка, фильтрация и экспорт
- **openpyxl**: запись файлов `.xlsx`

## Быстрый старт

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/agiknightt/scraper_portfolio.git
   cd scraper_portfolio
   ```

2. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Запустите скрипт:

   ```bash
   python parsing_project.py
   ```

## Результат

Скрипт обходит 5 страниц, фильтрует записи и сохраняет их в файл `quotes_filtered.xlsx`.

| Колонка | Описание                       |
|---------|--------------------------------|
| text    | текст цитаты                   |
| author  | автор                          |
| tags    | теги через запятую             |

## Особенности реализации

- **Защита от блокировок:** подмена заголовка User-Agent, задержки `time.sleep()` между запросами.
- **Отказоустойчивость:** обработка сетевых ошибок через `try/except`, таймауты на запросы (скрипт не зависнет, если сайт недоступен).
- **Очистка данных:** списки тегов преобразуются в строку через запятую для корректного отображения в Excel.
